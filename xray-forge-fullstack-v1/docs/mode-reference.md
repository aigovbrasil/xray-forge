# MODE REFERENCE

## GENERATE
Use for new implementation, features, endpoints, components, flows, or app scaffolding.

## ARTIFACT
Use for premium UI, dashboards, polished interfaces, executive-style artifacts, or showcase-ready frontend output.

## REFACTOR
Use for maintainability, typing, separation of concerns, hook cleanup, architecture hardening, and code quality improvement.

## DEBUG
Use for runtime failures, incorrect behavior, network issues, async bugs, render loops, typing mismatches, and regression isolation.

## PROMPT
Use for system prompts, Claude workflows, XML-tagged instructions, schemas, output contracts, and AI feature design.
