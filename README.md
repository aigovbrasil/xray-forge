# Workflow: X-RAY-FORGE - Geração de Artefatos Premium

## Objetivo
Atuar como um motor de geração de artefatos de frontend de nível de produção, garantindo consistência de marca e suporte a múltiplas linguagens visuais. Produzir entregáveis de alta qualidade para diversas finalidades.

## ICP (Ideal Customer Profile)
Design-conscious founders, product designers, frontend devs.

## Fases do Workflow

### Fase 1: Definição do Artefato (What)
*   **O Quê:** Especificação do tipo de artefato a ser gerado (ex: landing page, dashboard, componente UI, apresentação).
*   **Como:** Interação com o usuário para entender os requisitos visuais, funcionais e de conteúdo.
*   **Output:** Brief detalhado do artefato, incluindo referências de estilo e propósito.

### Fase 2: Seleção da Linguagem Visual (How)
*   **O Quê:** Escolha da linguagem visual e tema (dark/light mode, brand consistency).
*   **Como:** Utiliza skills de design e brand layer para aplicar estilos pré-definidos ou criar novos.
*   **Output:** Definição da identidade visual do artefato.

### Fase 3: Geração do Conteúdo e Estrutura (Where)
*   **O Quê:** Criação do conteúdo textual e estrutural do artefato.
*   **Como:** Skills de codificação (para componentes web), visual canvas (para layouts) e integração de dados (para dashboards).
*   **Output:** Esboço ou protótipo do artefato com conteúdo e layout básicos.

### Fase 4: Refinamento e Otimização (Why)
*   **O Quê:** Ajustes finos no design, otimização para diferentes plataformas e garantia de responsividade.
*   **Como:** Skills de revisão de design, testes de usabilidade e otimização de performance.
*   **Output:** Artefato final otimizado e pronto para produção.

## Skills Envolvidas (Exemplos)
*   `xray-forge-coding-v1`
*   `xray-forge-fullstack-v1`
*   `xray-forge-visual-canvas-v1`

## Pontos de Controle
*   Adesão aos requisitos visuais e funcionais.
*   Consistência com a identidade de marca.
*   Qualidade do código e responsividade.
*   Usabilidade e experiência do usuário.

## Interdependências
*   Pode receber inputs de `X-RAY-ANALYTICS` para visualização de dados.
*   Pode ser acionado por `X-RAY-EXECUTIVE` para geração de apresentações e relatórios.
*   Seus outputs podem ser entregues via `X-RAY-DELIVERY`.
