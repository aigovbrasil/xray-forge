# MODE REFERENCE

## GENERATE
Use when the user wants new code from a description.

## ARTIFACT
Use when the user wants a polished React artifact, premium component, or presentable frontend output.

## REFACTOR
Use when existing code should be improved structurally without unnecessary rewrite.

## DEBUG
Use when something is broken, failing, or behaving incorrectly.

## PROMPT
Use when the user needs a coding-oriented system prompt or prompt package for another AI.
